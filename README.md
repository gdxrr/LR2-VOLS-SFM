# ВОЛС Моделирование

Компьютерное структурно-функциональное моделирование волоконно-оптических линий связи (ВОЛС) и оценка качества передачи сигнала.

## Описание

Приложение для моделирования и анализа волоконно-оптических линий связи с графическим интерфейсом на PyQt5. Позволяет:

- Создавать и редактировать структурно-функциональные модели ВОЛС
- Рассчитывать параметры передачи сигнала
- Анализировать качество линии связи
- Визуализировать результаты расчетов
- Сохранять и загружать данные в форматах CSV и XLSX

## Требования

- Python 3.7+
- PyQt5
- NumPy
- Matplotlib
- openpyxl (для работы с Excel файлами)

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Структура проекта

- `main.py` - главный файл приложения с GUI
- `calculations.py` - модуль расчетов параметров ВОЛС
- `io_utils.py` - утилиты для импорта/экспорта данных
- `results_window.py` - окно отображения результатов
- `requirements.txt` - зависимости проекта
